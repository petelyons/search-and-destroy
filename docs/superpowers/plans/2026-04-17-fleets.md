# Fleets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Introduce the Fleet concept — a player-formed group of sea units led by a capital-ship flagship, with AI-driven followers (screens and transports) that the player does not steer directly.

**Architecture:** A `Fleet` domain object holds an owner, a flagship, and members keyed by role (`FleetRole: FLAGSHIP, SCREEN, TRANSPORT`). `Unit` gets a back-reference to its fleet. A `FleetRegistry` owned by `Game` tracks all live fleets and is the single source of truth for lookup and lifecycle (form / add / leave / flag-transfer / disband). Follower behavior is encoded in a new persistent `FleetMember` order whose per-turn logic branches on role. The human player moves only the flagship; after every flagship step, each non-flagship member takes its turn, driven by role-specific AI (screens prioritize intercept → interpose → trail; transports and reserve capitals trail the flagship). UI adds a JavaFX `FleetMode` picker to form/grow a fleet and a rendering overlay (flag icon on flagship, small pennant on members). Serialization adds a top-level fleets section restored in a second pass after units exist.

**Tech Stack:** Java 17, Maven, JUnit 5, JavaFX, existing Game/Order/GameCommand/GameEventBus infrastructure.

## Behavioral Spec (source of truth for review)

1. **Eligibility.** A fleet must have exactly one flagship. Flagship-eligible types: `BATTLESHIP`, `CARRIER`. Screen-eligible types: `DESTROYER`, `CRUISER`, `SUBMARINE`. Transport-eligible: `TRANSPORT`. Non-flagship capital ships that are members are tagged `SCREEN` (they behave as screens for movement but are candidates for flag transfer).
2. **Forming.** The player selects a flagship-eligible unit and zero-or-more eligible members. All members must be same-owner, Travel.SEA, not already in another fleet, and not carried.
3. **Movement.** Only the flagship is moved by the player. Other members are driven by `FleetMember` order, which replaces whatever order they had before joining. Leaving the fleet clears the `FleetMember` order and wakes the unit.
4. **Trail formation.** After every flagship step (not only at end of turn), each member moves one step toward its preferred position (see §6 / §7).
5. **Flag transfer.** If the flagship dies OR the player decouples it, the registry picks the next flagship-eligible member (insertion order) and re-tags it `FLAGSHIP`. If none, disband.
6. **Screen behavior (priority order).**
   1. **Intercept:** if any visible enemy unit is within `screen.getType().getDist()` hexes of flagship OR of any fleet transport, step toward that enemy.
   2. **Interpose:** step toward the hex on the ring `screen.visionDistance` from the flagship that lies on the vector between flagship and the nearest known enemy. If no known enemy, pick the detection-ring hex nearest the flagship's last heading (flagship's previous location → flagship's current location extended).
   3. **Trail:** step toward a follower slot no farther than 2 hexes from the flagship.
7. **Transport / reserve-capital behavior.** Step toward a follower slot within 2 hexes of the flagship. No combat initiative.
8. **Disband conditions.** (a) Flagship dies and no remaining member is flagship-eligible; (b) last non-flagship member leaves and the flagship decouples; (c) explicit disband command. All surviving members become independent (fleet reference cleared, order cleared, woken).
9. **Rendering.** Flagship gets a gold-star overlay in the top-right corner of its unit square. Non-flagship members get a small white pennant overlay in the top-right corner. Both drawn on top of the unit icon.
10. **Serialization.** Fleets saved as a top-level JSON array with `{id, ownerId, flagshipId, members:[{unitId, role}]}`. Restored after units exist. Units with active `FleetMember` orders record `{fleetId, role}` in `orderData`.

```java
// Fleet.java
package com.developingstorm.games.sad;

import java.util.Collections;
import java.util.LinkedHashMap;
import java.util.Map;

public class Fleet {

    private final long id;
    private final Player owner;
    private Unit flagship;
    private final Map<Unit, FleetRole> members = new LinkedHashMap<>();

    public Fleet(long id, Player owner, Unit flagship) {
        if (owner == null || flagship == null) {
            throw new SaDException("Fleet requires owner and flagship");
        }
        if (!flagship.getType().isCapitalShip()) {
            throw new SaDException(
                "Flagship must be a capital ship, got " + flagship.getType());
        }
        if (flagship.getOwner() != owner) {
            throw new SaDException("Flagship owner mismatch");
        }
        this.id = id;
        this.owner = owner;
        this.flagship = flagship;
        this.members.put(flagship, FleetRole.FLAGSHIP);
    }

    public long getId() { return id; }
    public Player getOwner() { return owner; }
    public Unit getFlagship() { return flagship; }
    public int size() { return members.size(); }
    public Map<Unit, FleetRole> membersView() {
        return Collections.unmodifiableMap(members);
    }
    public FleetRole roleOf(Unit u) { return members.get(u); }
    public boolean contains(Unit u) { return members.containsKey(u); }

    void addMember(Unit u, FleetRole role) {
        if (u == null || role == null) throw new SaDException("null member or role");
        if (members.containsKey(u)) throw new SaDException("unit already in fleet");
        members.put(u, role);
    }

    void removeMember(Unit u) {
        members.remove(u);
    }

    void setFlagship(Unit newFlagship) {
        if (!members.containsKey(newFlagship)) {
            throw new SaDException("new flagship must be a member");
        }
        if (flagship != null && members.containsKey(flagship)) {
            members.put(flagship, FleetRole.SCREEN);
        }
        this.flagship = newFlagship;
        members.put(newFlagship, FleetRole.FLAGSHIP);
    }
}
```

```java
// FleetRegistry.java
package com.developingstorm.games.sad;

import java.util.ArrayList;
import java.util.Collection;
import java.util.Collections;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public class FleetRegistry {

    private final Map<Long, Fleet> byId = new LinkedHashMap<>();
    private long nextId = 1L;

    public Collection<Fleet> allFleets() {
        return Collections.unmodifiableCollection(byId.values());
    }

    public Fleet byId(long id) { return byId.get(id); }

    public Fleet form(Unit flagship, List<Unit> initialMembers) {
        if (flagship == null) throw new SaDException("null flagship");
        if (flagship.getFleet() != null) {
            throw new SaDException("flagship already in a fleet");
        }
        Fleet f = new Fleet(nextId++, flagship.getOwner(), flagship);
        flagship.setFleet(f);
        byId.put(f.getId(), f);
        for (Unit m : initialMembers) {
            add(f, m);
        }
        return f;
    }

    public void add(Fleet f, Unit u) {
        if (u == null) throw new SaDException("null member");
        if (u.getFleet() != null) {
            throw new SaDException("unit already in a fleet");
        }
        if (u.getOwner() != f.getOwner()) {
            throw new SaDException("fleet member must have same owner");
        }
        if (u.getTravel() != Travel.SEA) {
            throw new SaDException("fleet members must be SEA units");
        }
        if (u.isCarried()) {
            throw new SaDException("carried unit cannot join fleet");
        }
        f.addMember(u, roleFor(u));
        u.setFleet(f);
    }

    public void leave(Unit u) {
        Fleet f = u.getFleet();
        if (f == null) return;
        boolean wasFlagship = u == f.getFlagship();
        f.removeMember(u);
        u.setFleet(null);
        if (wasFlagship) {
            Unit next = pickNewFlagship(f);
            if (next != null) {
                f.setFlagship(next);
            } else {
                disband(f);
            }
        } else if (f.size() <= 1 && (f.getFlagship() == null || !hasFollower(f))) {
            // flagship alone — allowed; do not disband.
        }
    }

    public void onUnitDied(Unit u) {
        leave(u);
    }

    public void disband(Fleet f) {
        List<Unit> snapshot = new ArrayList<>(f.membersView().keySet());
        for (Unit m : snapshot) {
            f.removeMember(m);
            m.setFleet(null);
        }
        byId.remove(f.getId());
    }

    private Unit pickNewFlagship(Fleet f) {
        for (Unit m : f.membersView().keySet()) {
            if (m.getType().isCapitalShip()) return m;
        }
        return null;
    }

    private boolean hasFollower(Fleet f) {
        return f.size() > 1;
    }

    private FleetRole roleFor(Unit u) {
        if (u.getType() == Type.TRANSPORT) return FleetRole.TRANSPORT;
        return FleetRole.SCREEN;
    }
}
```

```java
// orders/FleetMember.java
package com.developingstorm.games.sad.orders;

import com.developingstorm.games.hexboard.Location;
import com.developingstorm.games.sad.Fleet;
import com.developingstorm.games.sad.FleetRole;
import com.developingstorm.games.sad.Game;
import com.developingstorm.games.sad.Order;
import com.developingstorm.games.sad.OrderResponse;
import com.developingstorm.games.sad.OrderType;
import com.developingstorm.games.sad.ResponseCode;
import com.developingstorm.games.sad.SaDException;
import com.developingstorm.games.sad.Unit;
import com.developingstorm.games.sad.util.Log;

public class FleetMember extends Order {

    private final Fleet fleet;

    public FleetMember(Game g, Unit u, Fleet fleet) {
        super(g, u, OrderType.FLEET_MEMBER);
        if (fleet == null) throw new SaDException("FleetMember requires fleet");
        if (!fleet.contains(u)) {
            throw new SaDException("unit is not a member of the given fleet");
        }
        this.fleet = fleet;
    }

    public Fleet getFleet() { return fleet; }

    @Override
    public OrderResponse executeInternal() {
        if (u().getFleet() != fleet) {
            return new OrderResponse(ResponseCode.CANCEL_ORDER, this, null);
        }
        Unit flagship = fleet.getFlagship();
        if (flagship == null || flagship.isDead()) {
            return new OrderResponse(ResponseCode.CANCEL_ORDER, this, null);
        }
        FleetRole role = fleet.roleOf(u());
        if (role == FleetRole.FLAGSHIP) {
            // Flagship never has a FleetMember order.
            return new OrderResponse(ResponseCode.CANCEL_ORDER, this, null);
        }
        return stepTowardTrailSlot(flagship);
    }

    private Unit u() { return this.unit; }

    private OrderResponse stepTowardTrailSlot(Unit flagship) {
        Location target = flagship.getLocation();
        int dist = u().getLocation().distance(target);
        if (dist <= 2) {
            return new OrderResponse(ResponseCode.TURN_COMPLETE, this, null);
        }
        while (u().life().movesLeft() > 0 && !u().isDead()) {
            com.developingstorm.games.sad.Path path = u().getPath(target);
            if (path == null || path.isEmpty()) {
                return new OrderResponse(ResponseCode.TURN_COMPLETE, this, null);
            }
            Location next = path.next(u().getLocation());
            if (next == null) break;
            ResponseCode rc = this.game.resolveMove(u(), next, target);
            switch (rc) {
                case STEP_COMPLETE:
                    if (u().getLocation().distance(target) <= 2) {
                        return new OrderResponse(ResponseCode.TURN_COMPLETE, this, null);
                    }
                    break;
                case TURN_COMPLETE:
                    return new OrderResponse(ResponseCode.TURN_COMPLETE, this, null);
                case DIED:
                    return new OrderResponse(ResponseCode.DIED, this, null);
                case YIELD_PASS:
                    return new OrderResponse(ResponseCode.YIELD_PASS, this, null);
                default:
                    Log.warn(u(), "FleetMember unexpected rc: " + rc);
                    return new OrderResponse(ResponseCode.TURN_COMPLETE, this, null);
            }
        }
        return new OrderResponse(ResponseCode.TURN_COMPLETE, this, null);
    }
}
```

```java
// brain/ScreenFleetBehavior.java
package com.developingstorm.games.sad.brain;

import com.developingstorm.games.hexboard.Location;
import com.developingstorm.games.sad.*;
import java.util.ArrayList;
import java.util.List;

public final class ScreenFleetBehavior {

    private ScreenFleetBehavior() {}

    public static Location chooseMove(Unit screen, Fleet fleet, Game game) {
        Unit flagship = fleet.getFlagship();
        if (flagship == null) return null;

        Location intercept = pickInterceptTarget(screen, fleet, game);
        if (intercept != null) return stepToward(screen, intercept);

        Location interpose = pickInterposeTarget(screen, fleet, game);
        if (interpose != null) return stepToward(screen, interpose);

        return stepToward(screen, flagship.getLocation());
    }

    /** Return the location of the closest visible enemy within screen's dist of flagship/transport, or null. */
    private static Location pickInterceptTarget(Unit screen, Fleet fleet, Game game) {
        int r = screen.getType().getDist();
        List<Unit> protectees = new ArrayList<>();
        protectees.add(fleet.getFlagship());
        for (var e : fleet.membersView().entrySet()) {
            if (e.getValue() == FleetRole.TRANSPORT) protectees.add(e.getKey());
        }
        Player owner = fleet.getOwner();
        Location best = null;
        int bestDist = Integer.MAX_VALUE;
        for (Contact c : owner.getAllContacts()) {
            if (!c.isCurrent(game.getTurn())) continue;
            for (Unit p : protectees) {
                int d = c.location.distance(p.getLocation());
                if (d <= r && d < bestDist) {
                    bestDist = d;
                    best = c.location;
                }
            }
        }
        return best;
    }

    /** Pick a hex on screen's vision ring around the flagship, along the vector toward the nearest known enemy. */
    private static Location pickInterposeTarget(Unit screen, Fleet fleet, Game game) {
        Unit flagship = fleet.getFlagship();
        int ring = screen.getType().getVisionDistance();
        Player owner = fleet.getOwner();
        Contact nearest = null;
        int best = Integer.MAX_VALUE;
        for (Contact c : owner.getAllContacts()) {
            int d = c.location.distance(flagship.getLocation());
            if (d < best) { best = d; nearest = c; }
        }
        if (nearest == null) return null;
        List<Location> candidates = flagship.getLocation().getRing(ring);
        Location chosen = null;
        int bestScore = Integer.MAX_VALUE;
        for (Location l : candidates) {
            if (MapState.isBlocked(l, true)) continue;
            int score = l.distance(nearest.location);
            if (score < bestScore) { bestScore = score; chosen = l; }
        }
        return chosen;
    }

    private static Location stepToward(Unit screen, Location target) {
        if (target == null) return null;
        if (screen.getLocation().equals(target)) return target;
        com.developingstorm.games.sad.Path p = screen.getPath(target);
        if (p == null || p.isEmpty()) return null;
        return p.next(screen.getLocation());
    }
}
```

```java
            selected.add(target);
        }
        canvas.refresh();
    }

    @Override
    public boolean onKeyPressed(KeyEvent event) {
        if (event.getCode() == KeyCode.ENTER) {
            controller.formFleet(flagship, selected);
            canvas.getModeManager().switchMode(UIMode.GAME);
            return true;
        }
        if (event.getCode() == KeyCode.ESCAPE) {
            canvas.getModeManager().switchMode(UIMode.GAME);
            return true;
        }
        return false;
    }

    @Override
    public void draw(GraphicsContext gc) {
        gc.setStroke(Color.GOLD);
        gc.setLineWidth(3.0);
        for (Unit u : selected) {
            double[] c = canvas.getHexCenter(u.getLocation());
            gc.strokeOval(c[0] - 18, c[1] - 18, 36, 36);
        }
        double[] fc = canvas.getHexCenter(flagship.getLocation());
        gc.setStroke(Color.ORANGE);
        gc.setLineWidth(3.5);
        gc.strokeOval(fc[0] - 20, fc[1] - 20, 40, 40);
    }

    private boolean isEligibleMember(Unit u) {
        if (u.getOwner() != flagship.getOwner()) return false;
        if (u == flagship) return false;
        if (u.getFleet() != null) return false;
        if (u.getTravel() != Travel.SEA) return false;
        if (u.isCarried()) return false;
        Type t = u.getType();
        return t == Type.DESTROYER || t == Type.CRUISER || t == Type.SUBMARINE
            || t == Type.CARRIER || t == Type.BATTLESHIP || t == Type.TRANSPORT;
    }
}
```
